## Technical Decisions & Rationale

- **Rule 8 Opaque Proxy Standard**: Forwarding third-party tracking statuses or error objects introduces significant vulnerability and credential leakage vectors. Enforcing generic `204`/`502` returns shields host application domains while preserving downstream analytical tracking capabilities.
- **Stateless Sub-App Architecture**: Mountable Hono routers allow developers to easily embed the ConsentGuard proxy inline with existing route pipelines (`app.route('/analytics', consentProxyMiddleware(...))`) while preserving the flexibility of running inside stateless edge workers.
- **Defensive Error Handling**: Silent fallback states route exceptions or network proxy failures to close by default.
